# Salon — rendez-vous en ligne

Application de prise de rendez-vous pour un salon de coiffure : Vite, React, TypeScript et Supabase.

- `npm install` puis `npm run dev`
- Copier `.env.example` en `.env.local` et renseigner l'adresse et la clé publique du projet Supabase.
- La base est décrite par les migrations de `supabase/migrations`.
